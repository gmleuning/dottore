# 665 Reproductive Memory
# Spirit › 1. Subjective Spirit › III. Mind (Psychology) › α. Theoretical Mind › b. Representation › iii. Memory
G: Reproduktives Gedächtnis
Gloss: Memory that grasps a meaning directly in its name.
HGloss: Memory that has the thing in the name and recognizes the meaning in the name without image or intuition.

N:
  reproductive memory; recall of meaning from words, verbal recall, understanding through names, retrieval; thinking in names, word-meaning link
  reproducing memory, imageless recollection, the name as the thing, understanding in the name, recall of meaning

# ---- Hegel ----
Def: Reproductive memory has and recognizes the thing in the name, and with the thing the name, without intuition or image. The name as understood is the simple imageless representation: given the name lion, we need neither the animal nor its picture. It is in names that we think. Hegel rejects the mnemonics that turns names back into images, which reduces memory to imagination.
