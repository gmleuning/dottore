# ---- Hegel ----
Def: The now is the temporal form of the sensuous this. The now that is night, once written down, has by midday turned stale; the now maintains itself, but as a negative that is neither night nor day, and so as a universal. When it is pointed out, it has already ceased to be: it is only as what has been. Pointing it out is therefore a movement which returns to it as reflected into itself, a now that contains many nows, as a day contains hours, and it is experienced as a result and a universal.
