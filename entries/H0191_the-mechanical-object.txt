# 191 The Mechanical Object
# Logic › 3. Doctrine of the Concept › II. Objectivity › α. Mechanism
G: Das mechanische Objekt
Gloss: A thing complete in itself and related to others only from outside.

# ---- Hegel ----
Def: The mechanical object is the syllogism whose mediation has settled into immediate identity, a universality that pervades particularity and in it is immediate singularity. It has neither matter and form nor properties and accidents, since those relations belong to a past the concept has ended. Without determinate opposition within, it holds an indifferent manifold, so that there are several objects, each an aggregate in itself; yet it does not consist of atoms.
