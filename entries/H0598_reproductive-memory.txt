# 598 Reproductive Memory
# Spirit › 1. Subjective Spirit › III. Mind (Psychology) › α. Theoretical Mind › b. Representation › iii. Memory
G: Reproduktives Gedächtnis
Gloss: Memory that grasps a meaning directly in its name.

N:
  reproductive memory; recall of meaning from words, verbal recall, understanding through names, retrieval; thinking in names, word-meaning link
  reproducing memory, imageless recollection, the name as the thing, understanding in the name, recall of meaning

V:
  recall, retrieve, reproduce, understand by the word
  recognize, understand in the name

Adj:
  reproductive, retrievable, verbal
  imageless, recollective

Adv:
  on hearing the name
  in the name, without image, by name

Phr:
  we think in names [Hegel, paraphrased]
