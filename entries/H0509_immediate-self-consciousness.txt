# ---- Hegel ----
Def: Immediate self-consciousness is desire. The simple I is at first its own pure object and can be certain of itself only by sublating the other, which presents itself as self-sufficient life. Certain that this other is nothing, it makes this nullity its truth and destroys the object. But its satisfaction is conditioned by the object, which must be there to be sublated, so that desire reproduces both the object and itself. It can reach satisfaction only if the object negates itself, and so only in another self-consciousness.
