# ---- Hegel ----
Def: Satisfaction is the reflection of self-consciousness into itself, the certainty that has become truth, which desire reaches by sublating its object. But in this very satisfaction self-consciousness learns that the object is self-sufficient, since its certainty depends on there being something to sublate. It must be absolutely for itself, and can be so only by sublating the object; true satisfaction therefore requires an object that carries out the negation in itself, which only another self-consciousness does.
