# 88 Identity
# Logic › 2. Doctrine of Essence › I. Essence as Reflection Within Itself › β. Determinations of Reflection
G: Identität
Gloss: Sameness with oneself; not the empty formula A = A, but a self-sameness that already contains difference, since to be the same as oneself is to be distinguished from what is other.
HGloss: Essence's simple self-relation, which is not abstract A = A but an identity that contains difference within itself.
